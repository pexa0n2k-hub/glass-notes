# Glass Notes V3.1 — Nexus Visual

Rediseño visual del Home basado en el mockup Nexus/Liquid Glass.

## Alcance
- Nuevo dashboard móvil estilo cyberpunk / Liquid Glass.
- Cabecera HUD con búsqueda y ajustes.
- Resumen de pagos, pendientes y notas.
- Panel JARVIS visual.
- Acciones rápidas.
- Paneles de pendientes, próximos pagos y notas recientes.
- Se conserva la clave de almacenamiento y la lógica de módulos de la base V2.9.0/V3.0.

## Importante
Esta versión es principalmente visual. JARVIS por voz y las notificaciones reales se implementarán en versiones posteriores.


## V3.2 — JARVIS Voice
- Reconocimiento de voz en español (Chrome Android / Web Speech API).
- Respuestas habladas con SpeechSynthesis.
- Comandos locales para notas, pendientes, pagos y navegación.
- Respuesta por voz configurable desde Ajustes.

## V3.3 — JARVIS Core
- Intérprete ampliado para comandos naturales en español.
- Crea notas, pendientes y pagos desde voz.
- Soporta referencias simples a hoy/mañana en pendientes y pagos.
- Consulta pendientes, notas y pagos.
- Navega a Inicio, Notas, Pendientes, Pagos y Ajustes.
