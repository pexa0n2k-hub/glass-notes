# Glass Notes V3.4.5 — Pagos por mes

Actualización para separar los pagos por mes de vencimiento/fecha. Incluye secciones para el mes actual, el siguiente y el tercer mes; también crea secciones adicionales para otros meses con pagos y conserva la categoría de pagos sin fecha. Las pestañas Pendientes y Liquidados siguen funcionando por separado.

## Subir a GitHub Pages
Reemplaza `index.html`, `sw.js` y `manifest.json` en la raíz del repositorio `pexa0n2k-hub/glass-notes` y espera a que GitHub Pages publique los cambios.
